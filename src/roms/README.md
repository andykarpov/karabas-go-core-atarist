# ROMs

- `etos192uk.img`: EmuTOS 1.4, 192 KB, UK (from MiSTeryNano `sim/`). EmuTOS is free software,
  GPL v2 or later: https://emutos.sourceforge.io/ (sources: https://github.com/emutos/emutos).
  The default TOS of the core and of the simulation.

Atari TOS images are not in this repository: they come from the SD card (`/atarist`).
