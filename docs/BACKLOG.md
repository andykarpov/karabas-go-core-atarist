## Потом

- MIDI: USB MIDI IN прошивки (`CMD_MIDI`) → ACIA MIDI (`midi_rx`); выход — SAM2695.
- Физический дисковод Go (WD1772 на реальный привод).
- Последовательный порт MFP через USB-UART / ESP (`serial_*` апстрима).
- Принтер, донглы Cubase.
- Ф2, проверить на плате: защита записи образа только для чтения; игры с дискет.
- Слайсы заняты на 97 % (Mini G): ACSI в Ф3 может не поместиться, ужимать (например, таблицу делителей UART в MFP).
- После подключения ACSI заново прочитать в `.syr` выброшенные регистры `dma` / `acsi`: XST молча убирает регистры без начального значения и сброса (так было с `sd_state`).
