# Бэклог ядра Atari ST

## Решить

- (решено 2026-11-08: fx68k через `sv2v`; ST RAM в SDRAM, TOS в SRAM; имя `atarist`, `/atarist`, порядок 17; EmuTOS в `.kg` по умолчанию, TOS пользователя — файлом `FL`; ПЗУ IKBD апстрима — в репозитории и в `.kg`.)
- Лицензии: у MiSTeryNano нет файла LICENSE в корне; заголовки файлов Харбаума — GPL v3, fx68k — GPL v3, jt49 — GPL v3; проверить gstmcu / MiSTery до открытия репозитория.

## Проверить

- Примет ли монитор пользователя 626 строк при 31,25 кГц (удвоенный PAL ST) так же, как 625 у nanomig.
- Хватит ли SDRAM на 32 МГц шине ST: доступы CPU и видео, регенерация (апстрим так и работает на Primer 25K).

## Потом

- MIDI: USB MIDI IN прошивки (`CMD_MIDI`) → ACIA MIDI (`midi_rx`); выход — SAM2695.
- Физический дисковод Go (WD1772 на реальный привод).
- Последовательный порт MFP через USB-UART / ESP (`serial_*` апстрима).
- Принтер, донглы Cubase.
