# Atari ST / STE core for Karabas Go / Mini / Mini G

Work in progress: a port of [MiSTeryNano](https://github.com/harbaum/MiSTeryNano) (Till Harbaum's port of [MiSTery](https://github.com/gyurco/MiSTery) by Gyorgy Szombathelyi) to the Karabas boards (Xilinx Spartan-6 XC6SLX25).

The plan is in [docs/PLAN.md](docs/PLAN.md) (Russian).

Clone with `--recursive` (the `modules` submodule).
